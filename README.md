# 手机文件管理

一个自用 Android 文件管理 App，用于扫描手机内部存储并按类型统计文件。

## 已实现功能

- 按 5 类统计文件：文档、图片、视频、音乐、安装包
- 文档包含：Excel、PPT、Word、TXT、PDF
- 安装包包含：APK、APKS、XAPK
- 每个分类显示数量和总大小
- 文件列表显示文件名、大小、修改时间、所在目录
- 可以打开文件
- 可以进入文件所在目录，并高亮定位到该文件
- 目录页支持继续进入子目录、返回上一级

## 运行方式

1. 用 Android Studio 打开本目录：`D:\work\myApp`
2. 等待 Gradle 同步完成
3. 用 USB 连接小米 14，并开启开发者选项和 USB 调试
4. 点击 Run 安装到手机
5. 第一次打开 App 后点击“开启文件权限”
6. 在系统设置页允许“管理所有文件”
7. 返回 App，点击“重新扫描”

## 权限说明

小米 14 / Android 14 需要开启“管理所有文件”权限，否则普通 App 无法完整扫描手机存储。

本项目是自用文件管理工具，没有联网、上传或后台同步逻辑。
